# 個人心得

我的生圖想法是將圖片轉換為油畫風格來呈現。一開始的去雜訊強度只設定5.0，結果出來的圖片慘不忍睹。後來將其提升至7.0，便有了印象派油畫的風格，雖然乍看之下兩張圖差別很大，但仔細一看還是有相似的元素(人物雙手交叉、紅花綠葉)，雖然與我的預期不同，但我覺得很有趣。
